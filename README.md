# ثبات 🌱

تطبيق ويب بسيط لمتابعة العادات اليومية، يعمل بالكامل في المتصفح دون خادم أو حساب.

## العادات المتابَعة

- **الصلوات الخمس**: الفجر، الظهر، العصر، المغرب، العشاء (كل صلاة منفردة)
- **الأكل الصحي** 🥗
- **الرياضة** 🏃
- **الاستيقاظ المبكر** ⏰

## الصفحات

### ☀️ اليوم
- رسالة كتبتها لنفسك **أمس** تظهر لك صباح اليوم
- التأشير على الصلوات والعادات المنجزة مع حلقة تقدّم
- كتابة رسالة لنفسك تقرأها **غدًا** (تُحفظ تلقائيًا)

### 🔥 المتابعة
- مؤشر ستريك كأنه لعبة: مستويات (🌱 بذرة الثبات → 👑 أسطورة الثبات) وشريط تقدّم نحو المستوى التالي
- إحصاءات: أفضل ستريك، عدد الأيام المكتملة، نسبة إنجاز آخر ٧ أيام
- بطاقة لكل عادة فيها الستريك الحالي والأفضل وشبكة آخر ١٤ يومًا

## التشغيل

التطبيق ملفات ثابتة (HTML/CSS/JS) — افتح `index.html` مباشرة، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

ويمكن نشره مجانًا عبر **GitHub Pages**: من إعدادات المستودع → Pages → اختر الفرع الرئيسي.

## ملاحظات تقنية

- البيانات تُحفظ في `localStorage` في متصفحك — لا تُرسل لأي مكان
- يدعم الوضع الليلي (تلقائي حسب النظام مع زر تبديل)
- واجهة عربية كاملة من اليمين لليسار، مناسبة للجوال
